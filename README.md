# Portfolio (React + Vite + Tailwind v4 + Framer Motion)

1. `npm install`
2. `npm run dev`

Customize: edit `src/assets.js` (name, text, skills, projects, experience, contact).
Images: put your photo at `public/profile.jpg`; project images in `public/projects/` (names are in assets.js).
Missing images fall back to a gradient, so the site never looks broken.
